## 전략 실험실 (`/lab`)

> 아래 실험실 터미널 항목은 `기능명 — 설명` 형식으로 정리했습니다.

### 실험실 › 상단 시세 바

- 시세 바 종목 전환 버튼 — 종목명을 누르면 오른쪽 종목 패널이 열리고 검색창에 바로 입력할 수 있다.
- 시세 바 현재가·24시간 등락률 — 선택한 차트 종목의 실시간 현재가와 24시간 등락률을 상승 빨강·하락 파랑으로 보여준다.
- 시세 바 실시간 연결 상태 — 실시간 연결 · 연결 중 · Binance 현물 미상장 · 연결 끊김 상태를 표시한다.
- 시세 바 24시간 가격 범위 — 24시간 저가~고가 막대 위에 현재가 위치를 점으로 표시한다.
- 시세 바 24시간 거래대금·시가총액 — 선택 종목의 24시간 거래대금과 시가총액을 축약 단위로 보여준다.
- 시세 바 코인 상세 이동 — `코인 상세로 →` 링크로 해당 종목의 `/trade/[symbol]` 화면으로 이동한다.

### 실험실 › 차트 툴바

- 차트 툴바 시간봉 선택(1분~1주) — 선택된 차트의 시간봉을 1분·5분·15분·1시간·4시간·1일·1주 중에서 바꾼다.
- 차트 툴바 보조지표 메뉴 — 선택된 차트에 거래량·이동평균선 20·60·볼린저 밴드·RSI를 켜고 끈다.
- 차트 툴바 내 지표·전략 메뉴 — Pine 편집기에서 저장한 지표·전략을 선택된 차트 위에 표시하거나, 편집기를 열어 새로 만든다.
- 차트 툴바 화면 분할 코인 선택(최대 6개·검색) — 코인 목록에서 이름·심볼·초성으로 검색해 최대 6개를 고르면, 고른 순서대로 1화면·2분할·3분할·2×2·위3아래2·3×2로 배치된다. 이미 열려 있던 코인은 시간봉·지표 설정을 유지한다.
- 차트 툴바 레이아웃 저장 — 분할 구성·종목·시간봉·지표를 브라우저에 저장해 다음 방문 때 그대로 연다. 저장하지 않은 변경이 있으면 점으로 표시한다.
- 차트 툴바 한국 시간 시계 — 현재 한국 시간(KST)을 보여준다.
- 차트 툴바 작도 실행 취소·다시 실행 — 선택 종목의 작도 변경을 되돌리거나 다시 적용한다(⌘Z / ⇧⌘Z, 종목별 최대 50단계).
- 차트 툴바 차트 이미지 저장 — 선택된 차트를 PNG 파일로 내려받는다.
- 차트 툴바 전체 화면 — 실험실 터미널 전체를 전체 화면으로 전환하거나 해제한다.

### 실험실 › 작도 도구 바

- 작도 도구 바 십자 커서 — 작도를 끝내고 기본 커서로 돌아간다(Esc).
- 작도 도구 바 추세선 — 두 지점을 클릭해 추세선을 긋는다.
- 작도 도구 바 수평선 — 가격 위치를 클릭해 수평선을 긋는다.
- 작도 도구 바 피보나치 되돌림 — 두 지점을 클릭해 피보나치 되돌림 구간을 그린다.
- 작도 도구 바 작도 숨기기 — 모든 차트의 작도를 잠시 숨기거나 다시 보인다.
- 작도 도구 바 작도 모두 지우기 — 선택 종목의 작도를 한 번에 지운다(실행 취소로 되돌릴 수 있음).

### 실험실 › 분할 차트

- 분할 차트 선택 차트 강조 — 클릭한 차트에 파란 테두리를 두르고, 툴바·시세 바·하단 패널이 그 차트를 기준으로 동작한다.
- 분할 차트 종목·시간·OHLC 범례 — 차트 좌상단에 종목·시간봉·적용 지표와 마우스 위치 봉의 시가·고가·저가·종가·전봉 대비 변동을 표시한다.
- 분할 차트 실시간 캔들 — TradingView Lightweight Charts로 Binance 현물 캔들을 그리고 주기적으로 갱신한다.
- 분할 차트 작도 안내 — 작도 도구를 고르면 차트 위에 어디를 클릭해야 하는지 안내를 띄운다.

### 실험실 › 오른쪽 패널

- 오른쪽 패널 종목 목록(전체·관심·최근 본) — 탭으로 전체·관심·최근 본 종목을 나눠 보고, 행을 누르면 선택된 차트의 종목이 바뀐다.
- 오른쪽 패널 종목 검색 — 이름·심볼·초성으로 종목을 찾는다.
- 오른쪽 패널 종목 정렬(거래대금·변동%) — 머리글을 눌러 거래대금 또는 변동률 기준으로 오름·내림차순 정렬한다.
- 오른쪽 패널 관심 종목 별표 — 별을 눌러 관심 종목에 추가·해제한다(헤더·홈과 공유).
- 오른쪽 패널 실시간 호가·체결 — 선택 종목의 Binance 호가와 최근 체결 내역을 보여준다.
- 오른쪽 패널 실시간 뉴스 — 최신 암호화폐 뉴스를 상대 시간과 함께 보여준다.
- 오른쪽 아이콘 레일 패널 전환 — 종목·호가·뉴스 패널을 열고 닫으며, Pine·백테스트·리플레이 하단 패널을 바로 연다. 좁은 화면에서는 패널이 차트 위에 겹쳐 열린다.

### 실험실 › 하단 패널

- 하단 패널 탭(Pine 편집기·전략 테스터·리플레이 연습) — 기존 실험실 기능을 선택된 차트의 종목·시간봉 기준으로 하단에서 연다. 한 번 연 탭은 작업 상태가 유지된다.
- 하단 패널 크게 보기·닫기 — 하단 패널을 화면 절반 크기와 최대 크기 사이에서 바꾸거나 닫는다.

### 실험실 › 하단 티커 바

- 하단 티커 바 관심 종목 시세 — 관심 종목의 현재가·등락률을 보여주고, 누르면 선택된 차트의 종목이 바뀐다.
- 하단 티커 바 데이터 출처·한국 시간 — 차트 데이터 출처(Binance 현물 종목)·한국 시간·TradingView 차트 제공 표기를 보여준다.
